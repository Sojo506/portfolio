# Proyecto: Portafolio profesional de Fabián Sojo — SOJO DEV

Quiero que diseñes y desarrolles un portafolio web profesional completo para mi marca personal **SOJO DEV**.

El sitio debe representar a **Fabián Sojo**, desarrollador Full Stack y estudiante de Ingeniería en Sistemas de Costa Rica.

No quiero una plantilla genérica de portafolio. Quiero una experiencia visual elegante, minimalista, sobria, moderna y completamente profesional.

---

## 1. Objetivo del sitio

El portafolio debe permitirme:

* Presentar claramente quién soy.
* Mostrar mi experiencia profesional.
* Publicar mis proyectos web.
* Explicar mi participación en cada proyecto.
* Mostrar las tecnologías que utilizo.
* Presentar mi educación, certificaciones e insignias digitales.
* Permitir descargar mi currículum.
* Facilitar que empresas, reclutadores o clientes se comuniquen conmigo.
* Transmitir una imagen profesional, confiable y preparada para trabajar en proyectos reales.

El sitio debe estar pensado tanto para conseguir oportunidades laborales como para captar posibles clientes de desarrollo web.

## 3. Dirección visual

Quiero un diseño:

* Minimalista.
* Blanco y negro.
* Elegante.
* Formal.
* Moderno.
* De alto nivel.
* Con bastante espacio en blanco.
* Con excelente jerarquía tipográfica.
* Con animaciones discretas y fluidas.
* Con apariencia de estudio creativo o agencia tecnológica premium.

### Paleta visual

Usar principalmente:

* Negro profundo.
* Blanco.
* Tonos grises neutros.
* Bordes gris claro.
* Fondos ligeramente contrastados.
* Un color de acento muy discreto solamente si aporta valor.

El sitio debe tener modo claro y modo oscuro.

### Tipografía

Usar una combinación tipográfica moderna y profesional.

Opciones recomendadas:

* Geist.
* Inter.
* Manrope.
* Instrument Sans.
* Space Grotesk para títulos puntuales.

Los encabezados deben tener gran presencia visual, pero sin perder formalidad.

### Estilo de los componentes

Los componentes deben usar:

* Bordes finos.
* Esquinas moderadamente redondeadas.
* Sombras muy suaves o inexistentes.
* Efectos hover elegantes.
* Separadores visuales.
* Animaciones cortas.
* Transiciones fluidas.
* Tarjetas limpias y bien espaciadas.
* Botones sólidos y secundarios claramente diferenciados.

Evita abusar de gradientes, glassmorphism, efectos de neón o animaciones llamativas.

* Que los componentes sean reutilizables.
* Que el código esté preparado para mantenimiento futuro.

Ejecuta, como mínimo:

```bash
pnpm lint
pnpm build
```

Corrige todos los errores antes de considerar el proyecto terminado.

## 33. Flujo de trabajo solicitado

Antes de comenzar a implementar:

1. Analiza todos los requerimientos.
2. Propón la estructura del proyecto.
3. Define el sistema visual.
4. Define las secciones y componentes.
5. Identifica decisiones que puedan afectar la escalabilidad.
6. Crea un plan por fases.
7. Después implementa cada fase.
8. Verifica el resultado al finalizar cada etapa.

No simplifiques funcionalidades importantes sin explicarlo.

Cuando exista una decisión entre varias alternativas, selecciona la opción que produzca el portafolio más profesional, mantenible, rápido y fácil de actualizar.

El resultado final debe sentirse como el portafolio de un desarrollador Full Stack serio y preparado para trabajar con empresas o clientes reales.
